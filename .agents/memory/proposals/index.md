# Proposals Index

This directory holds WGCP design proposals and RFC specifications.

* [P-001 Game Registry Specification (v2)](P-001-game-registry-spec-v2.md) - Approved proposal for the WGCP game registry structure inspired by F-Droid v2. [Status: accepted]
* [P-002 Game SDK & Portal Synchronization Specification](P-002-game-sdk-storage-sync.md) - Proposal for a lightweight, client-side Game SDK and iframe communication bridge to sync progress, settings, and scores with the console portal. [Status: proposed]
* [P-003 Game Services API Specification](P-003-game-sdk-services-api.md) - Proposal for the core game services SDK APIs (Identity, Achievements, Leaderboards, Settings, Telemetry) running on the WGCP console platform. [Status: proposed]
